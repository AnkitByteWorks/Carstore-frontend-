# Carstore Frontend

A beautiful, animated luxury car e-commerce frontend built with Next.js 15, Tailwind, and shadcn/ui.

## 🌐 Live Demo

https://carstore-frontend.vercel.app

## 🛠️ Tech Stack

- Next.js 15 (App Router)
- TypeScript
- Tailwind CSS
- shadcn/ui
- TanStack Query (React Query)
- Zustand (state management)
- Framer Motion (animations)
- React Hook Form + Zod

## 🚀 Local Development

```bash
npm install
npm run dev
```
